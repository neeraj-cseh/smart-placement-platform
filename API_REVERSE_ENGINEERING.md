# API Reverse Engineering Matrix

Base URL used by frontend: `http://127.0.0.1:8000/api` unless `VITE_API_URL` overrides it.

Default JSON headers:

```http
Content-Type: application/json
Authorization: Bearer <access_token>
```

Public endpoints omit `Authorization`. Default backend authentication is `rest_framework_simplejwt.authentication.JWTAuthentication`. Default permission is `IsAuthenticated` unless the view overrides it.
